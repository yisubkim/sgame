# 잊힌 길의 기록

발견이 곧 성장인 도트 오픈월드 RPG. 퀘스트도, 표시도 없다.

**플레이:** https://yisubkim.github.io/sgame/

- PC: 방향키/WASD 이동 · Z 공격·결정 · X 취소 · E 조사 · Space 구르기 · 1~6 기술 · C/I/K/M 메뉴 · H 조작법
- 휴대폰: 화면의 방향키와 버튼 (버튼 모서리의 작은 글자는 PC 키)
- 아이폰: 사파리로 연 뒤 공유 → 홈 화면에 추가하면 앱처럼 쓸 수 있다
- 저장은 쓰는 브라우저에 남는다 (자동 저장 + 설정 메뉴의 슬롯 1~3)

이 저장소에는 빌드된 게임 파일(`index.html`)만 있다.
